    Services & AI instructions

    Transcript services

    Gemini and the caption services use the API keys below. Antigravity downloads temporary local audio and uses your existing signed-in Antigravity CLI; its audio is deleted after every attempt.

    Google's full model list is shown. A listed model is not necessarily free or able to transcribe video; an unsupported choice fails clearly. Best first, one model ID per line. A structured daily-quota limit or an explicit high-demand/capacity HTTP 503 moves the failed clip and the rest of this batch to the next model; generic server errors and short-term rate limits keep their bounded retries.

    Gemini and Antigravity listen to the video's audio and write what they hear, so they ignore this setting. Supadata and FetchTranscript copy existing captions and use it to pick the caption language. Their AI transcription and automatic credit purchases are not enabled.

    AI assistant for Formatted, Summary and Ask AI

    Uses your installed CLI and existing login. Each call receives transcript context; the AI has no need for shell commands or file edits.

    Instructions sent with each request

    The original transcript is kept unchanged. AI corrections are suggestions and may need review.
