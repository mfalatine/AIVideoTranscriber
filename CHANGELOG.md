## [v0.2] - 2026-10-19

First public release

- Collect YouTube transcripts with Gemini transcription, existing-caption services, or the signed-in Antigravity CLI.
- Transcribe local video files with Whisper or Gemini.
- Keep a local transcript library and create formatted text, summaries, and transcript-based answers with a configured AI command-line tool.
- Run the dashboard on Windows with local data and Windows-account-protected API keys.
